# Specification: Content Expansion

**Track ID:** content-expansion_20260815
**Type:** Feature
**Created:** 2026-08-15
**Status:** Draft

## Summary

Implement the formally approved Aetheria Online Content Expansion, which introduces two new zones (Whispering Depths, Sky-Shattered Peaks), new tier-4 hybrid classes, a level 80 raid (The Sunken Cathedral), and new regional cartography quests.

## Context

Aetheria Online is a zero-build vanilla JS ES-module web-based RPG. The core loop consists of exploration, turn-based combat, and class progression.

## User Story

As a player, I want to explore new high-level zones, access advanced hybrid classes, fight a new raid boss, and complete new quests so that I have engaging endgame content to experience.

## Acceptance Criteria

- [ ] Whispering Depths zone is implemented with new tiles (`~`, `w`, `K`) and monsters (Tidecrawler, Abyssal Siren, Leviathan's Shadow).
- [ ] Sky-Shattered Peaks zone is implemented with new tiles (`_`, `^`) and monsters. Windstream forces movement with 1s immunity.
- [ ] Spellblade and Vanguard classes are implemented with their respective key skills.
- [ ] Set Bonuses logic is implemented and cached on `equip/unequip`.
- [ ] The Sunken Cathedral raid is implemented with 3 phases and soft enrage logic configurable via `js/design.js`.
- [ ] Aris the Cartographer NPC and the two Cartography Quests are implemented.

## Dependencies

Existing game engine and `js/design.js` configuration.

## Out of Scope

- Modifying existing classes or early game zones.
- New database or server architecture (must remain zero-build vanilla JS).

## Technical Notes

- Set bonuses recalculate only on equip/unequip.
- Windstream hooks into global environment tick, suspends physics on login until ready, and displays UI overlay.
- Boss aggro map is pruned on disconnect/zone change.
- Raid constraints (enrage stacks) driven by `js/design.js`.
